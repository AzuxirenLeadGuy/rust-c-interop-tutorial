# Static Libraries in C

A static library is a library that must be linked during the compile phase. This at first may sound the obvious way to build libraries, but there are certain advantages in building dynamic libraries that are worth checking out. It is detailed in the next chapter.

Like binaries, static libraries have to be compiled for a given operating system and CPU type. So if you are preparing a library to be used in windows for the x64 CPU, then it will be incompatible for a different operating system or CPU. Windows, in particular makes use of Microsoft's VC++ compilers, which heavily break the standard UNIX conventions (unlike MacOS), so for this tutorial, I will be referencing the GNU utilities, because [GNU compiler toolchain can also be utilised for windows](https://winlibs.com/)

## Manual preperation

The usage is straightforward as follows:

```
ar <your-static-lib>.a [collection of object files]
```
